# 🚀 Automatic Deployment Setup for Digital Ocean

This guide will help you set up automatic deployment from GitHub to your Digital Ocean server. Every time you push changes to your main branch, your site will automatically update.

## 📋 Prerequisites

- A Digital Ocean droplet with Ubuntu 20.04+ or Debian 11+
- Root access to your server
- A GitHub repository with your marketplace code
- A domain name pointing to your server (optional but recommended)

## 🔧 Setup Instructions

### Step 1: Prepare Your Server

1. **SSH into your Digital Ocean droplet:**
   ```bash
   ssh root@your-server-ip
   ```

2. **Clone your repository:**
   ```bash
   cd /var/www
   git clone https://github.com/yourusername/marketplace.git
   cd marketplace
   ```

3. **Make the setup script executable and run it:**
   ```bash
   chmod +x setup_deployment.sh
   sudo ./setup_deployment.sh
   ```

### Step 2: Configure Your Domain

1. **Edit the Nginx configuration:**
   ```bash
   sudo nano /etc/nginx/sites-available/webhook-handler
   ```

2. **Replace `your-domain.com` with your actual domain:**
   ```nginx
   server_name your-actual-domain.com;
   ```

3. **Test and reload Nginx:**
   ```bash
   sudo nginx -t
   sudo systemctl reload nginx
   ```

### Step 3: Set Up GitHub Webhook

1. **Go to your GitHub repository**
2. **Navigate to Settings → Webhooks**
3. **Click "Add webhook"**
4. **Configure the webhook:**
   - **Payload URL:** `http://your-domain.com/webhook`
   - **Content type:** `application/json`
   - **Secret:** Use the secret generated by the setup script
   - **Events:** Select "Just the push event"
   - **Active:** ✓

5. **Click "Add webhook"**

### Step 4: Configure Your Application

1. **Update the deployment script with your repository details:**
   ```bash
   sudo nano /var/www/marketplace/deploy.sh
   ```
   
   Change these lines:
   ```bash
   GIT_REPO="https://github.com/yourusername/marketplace.git"
   BRANCH="main"  # or "master" depending on your default branch
   ```

2. **Set up your Flask application service:**
   ```bash
   sudo nano /etc/systemd/system/marketplace.service
   ```
   
   Add this content:
   ```ini
   [Unit]
   Description=Marketplace Flask Application
   After=network.target
   
   [Service]
   User=www-data
   Group=www-data
   WorkingDirectory=/var/www/marketplace
   Environment=PATH=/var/www/marketplace/venv/bin
   ExecStart=/var/www/marketplace/venv/bin/gunicorn --workers 3 --bind 127.0.0.1:5000 app:app
   Restart=always
   
   [Install]
   WantedBy=multi-user.target
   ```

3. **Enable and start your application:**
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable marketplace
   sudo systemctl start marketplace
   ```

## 🔍 Testing Your Setup

### Test the Webhook Handler

1. **Check if the webhook handler is running:**
   ```bash
   sudo systemctl status webhook-handler
   ```

2. **Test the health endpoint:**
   ```bash
   curl http://your-domain.com/health
   ```

3. **Test manual deployment:**
   ```bash
   curl -X POST -H "X-API-Key: YOUR_MANUAL_DEPLOY_KEY" http://your-domain.com/deploy
   ```

### Test Automatic Deployment

1. **Make a small change to your code**
2. **Commit and push to GitHub:**
   ```bash
   git add .
   git commit -m "Test deployment"
   git push origin main
   ```

3. **Check the logs to see if deployment was triggered:**
   ```bash
   tail -f /var/log/webhook.log
   tail -f /var/log/marketplace-deploy.log
   ```

## 🔧 Troubleshooting

### Common Issues

1. **Webhook not triggering:**
   - Check if the webhook handler is running: `sudo systemctl status webhook-handler`
   - Verify the webhook URL is accessible from GitHub
   - Check the webhook secret matches

2. **Deployment fails:**
   - Check deployment logs: `tail -f /var/log/marketplace-deploy.log`
   - Verify file permissions: `ls -la /var/www/marketplace/`
   - Check if the virtual environment exists

3. **Application not starting:**
   - Check application logs: `sudo journalctl -u marketplace -f`
   - Verify dependencies are installed: `pip list`
   - Check if the port is available: `netstat -tlnp | grep 5000`

### Reset Everything

If you need to start over:

```bash
# Stop services
sudo systemctl stop webhook-handler
sudo systemctl stop marketplace

# Remove configurations
sudo rm /etc/systemd/system/webhook-handler.service
sudo rm /etc/systemd/system/marketplace.service
sudo rm /etc/nginx/sites-enabled/webhook-handler
sudo rm /etc/sudoers.d/webhook-deploy

# Reload systemd
sudo systemctl daemon-reload

# Restart Nginx
sudo systemctl reload nginx
```

## 🔒 Security Considerations

1. **Keep secrets secure:**
   - Store webhook secrets securely
   - Use environment variables for sensitive data
   - Regularly rotate secrets

2. **Firewall configuration:**
   - Only allow necessary ports (22, 80, 443)
   - Consider using a VPN for SSH access

3. **Regular updates:**
   - Keep your system updated
   - Monitor for security patches

## 📝 File Structure

After setup, your server will have this structure:

```
/var/www/marketplace/
├── deploy.sh              # Deployment script
├── webhook_handler.py     # Webhook handler
├── webhook-handler.service # Systemd service file
├── setup_deployment.sh    # Setup script
├── app.py                 # Your Flask application
├── requirements.txt       # Python dependencies
└── venv/                 # Virtual environment
```

## 🎉 Success!

Once everything is set up, every time you push changes to your main branch on GitHub, your Digital Ocean server will automatically:

1. Pull the latest changes
2. Install/update dependencies
3. Run database migrations
4. Restart the application
5. Clear caches
6. Perform health checks

Your marketplace will be updated within minutes of each push! 🚀
